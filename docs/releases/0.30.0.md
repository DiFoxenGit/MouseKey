# MouseKey 0.30.0 — отладчик и разрешение конфликтов

18 ноября 2026 года.

## Русский

- Пошаговый отладчик: остановка перед первым блоком, пауза между действиями, продолжение, точки останова и значения переменных. Шаг входит во вложенные сценарии; остановка работает и на паузе.
- Разрешение конфликтов по блокам, настройкам и связям с предварительным сравнением результата. Можно сохранить обе версии вместе с независимыми копиями вложенных сценариев. Повторные изменения аккаунта защищены от перезаписи.
- Пять исправлений аудита: восстановление повреждённой библиотеки после резервной записи; случайная область не блокируется старой фиксированной точкой; проверка переменных следует связям графа; смена ПК скрывает устаревший предпросмотр; сравнение истории соответствует восстанавливаемому набору зависимостей.

Для удалённой отладки обновите **оба ПК до 0.30.0**. Сервер и прошивка ESP не менялись. Точки останова хранятся в текущем сеансе конструктора. Подпись автообновления использует прежний ключ; установщик не имеет Authenticode-подписи.

## English

- Action-boundary debugger with pause, continue, step into nested scenarios, breakpoints and variable values. Stop works while paused.
- Select local/account values per block, settings and connection, preview the merged result or keep both independent dependency trees. Newer account edits remain protected.
- Five regressions fixed: damaged-library recovery with raw backup; random-area preflight; route-aware variable analysis; target-bound recognition previews; restore-scope history comparison.

Update both PCs to 0.30.0 for remote debugging. No server or ESP firmware change. Breakpoints last for the current editor session. The existing updater key is preserved; the installer is not Authenticode-signed.

## Проверки / Validation

188 Rust tests passed, with one existing hardware-only test skipped; 712 TypeScript tests passed. The final aggregate gate and installer validation are recorded in release-manifest.json. Production dependency audit found no known vulnerabilities; dependency license/advisory policies passed. Manual review covered debug-command ownership/sequence, pause cancellation and input release, bounded atomic recovery backup and account conflict guards. Gitleaks, Semgrep, OSV Scanner and cargo-audit were unavailable; this is not a scanner pass.

UI checks covered Russian/English, 1280×720 and 600×900 layouts, pause/step/variable display, saving a selected resolution and keeping both versions, plus conflict dialogs in all six Toffee/Cocoa/Forest light/dark combinations. UI checks use synthetic input/account replies. Physical ESP execution, a live remote PC, production account writes and installing over the running application are not part of these isolated checks; no clean Windows VM was available.

Rollback: reinstall 0.29.0 if necessary. There is no scenario-format or server-schema migration. Export scenarios and retain local/account history before rollback.
