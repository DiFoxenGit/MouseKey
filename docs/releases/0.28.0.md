# MouseKey 0.28.0 — компактный конструктор

17 ноября 2026 года.

## Русский

- Компактные карточки сценариев сверху, больше места для схемы, раскрываемая библиотека снизу. Действия карточки, включая вставку связанного сценария, доступны в её меню; перетаскивание сохранено.
- Параметры поиска и OCR сгруппированы. Длительность движения и плавная траектория находятся рядом; дополнительные задержки раскрываются отдельно.
- Можно выделить несколько блоков и применить общий диапазон движения и траекторию. Удержание кнопки, паузы между кликами и связанные оригиналы не меняются; действие отменяется одним нажатием.
- Исправлены пять ошибок аудита: повторный импорт экспортированного JSON с эталонами, исчезновение верхней границы при редактировании диапазона, переполнение длинного имени карточки, неполные подписи движения/клика и устаревшая подсказка времени.
- Экспорт использует компактный JSON и проверяет возможность обратного чтения. Старые файлы с отступами принимаются до 4 МБ, при этом лимит содержимого документа остаётся 1 МБ, а лимиты действий и эталонов сохраняются.

Сценарии, учётная запись и настройки сохраняются. Обновление прошивки ESP и серверный патч для этого выпуска не нужны. Подпись автообновления использует прежний ключ; Authenticode-подписи у установщика нет.

## English

- Compact scenario cards, a larger canvas and a collapsible bottom library. Card menus retain insertion and reuse actions; dragging still adds live scenario links.
- Grouped image/OCR settings and cursor timing next to curved motion controls, with additional delays in a disclosure.
- Apply a common travel range and curve to selected movement blocks in one undoable edit. Button hold, click intervals and linked sources stay intact.
- Fixed all five audit findings: reference-heavy JSON round trips, disappearing range fields, long card names, incomplete movement/click summaries and the stale duration hint.
- Compact export validates its own import. Legacy formatted files up to 4 MB are accepted only when their compact document fits 1 MB; action/reference limits remain unchanged.

Existing data is preserved. No ESP firmware update or server deployment is required. Updates use the existing signing key; the installer is not Authenticode-signed.

## Проверки / Validation

- 177 Rust tests passed; one existing hardware-only test remains skipped. 684 TypeScript tests passed. Formatting, lint, types, doctests and dependency policies passed locally.
- Real editor UI with synthetic data: 1440×960, 1366×768 and 600×900; Russian/English; toffee dark, cocoa light and forest dark. Range editing, multi-selection/apply/undo, preset deletion/restore, long names and narrow-window panels checked.
- Test hardware/account responses do not verify ESP execution or production account synchronization. A clean Windows VM and screen reader were unavailable.
- CI and final installer/download verification are recorded separately in the release asset manifest; skipped checks are not counted as passes.

Rollback: reinstall 0.27.0 if necessary. This release adds no scenario execution format or server schema migration; keep an exported backup and local/account history before rollback.
