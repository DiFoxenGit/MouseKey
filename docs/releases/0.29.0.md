# MouseKey 0.29.0 — проверка сценариев перед запуском

18 ноября 2026 года.

## Русский

- Проверка схемы и параметров, эталонов, доступности ESP, окон, границ экрана и возможных неопределённых переменных. Ошибки блокируют запуск; из списка можно перейти к блоку. Проверка ничего не нажимает.
- «Запустить», «Запустить с этого блока» и «Только этот блок» расположены вместе над полотном. Отдельный блок выполняется один раз без продолжения по исходящим связям; цикл включает тело, вызов — вложенный сценарий.
- Поиск изображения и OCR показывают кадр, на котором выполнена проверка. Доступно увеличение, рамка совпадения, результат OCR и преобразования в число. После редактирования старый результат скрывается.
- Сравнение значений в истории и при конфликте сохранения: параметры, добавление/удаление блоков, связи и вложенные сценарии. Перемещение блоков отделено от правок действий.

Для удалённой проверки и предпросмотра обновите **оба ПК до 0.29.0**. Сценарии и настройки сохраняются; новый сервер и прошивка ESP не нужны. Подпись автообновления использует прежний ключ. Установщик не имеет Authenticode-подписи.

## English

- Read-only preflight checks graphs, references/parameters, ESP availability, screen bounds, windows and potentially unset variables. Errors block execution; issues navigate to their blocks.
- Run, Run from this block and Only this block share the top command bar. A single-block run does not follow its continuation; loops include their bodies and calls include their child scenario.
- Search/OCR previews use the exact captured frame, with an enlarged view, match rectangle and raw/numeric OCR results. Editing invalidates stale previews.
- Compare current/history or local/account values, including linked scenarios. Action edits, added/deleted blocks and connections are separate from layout changes.

Update both PCs to 0.29.0 for remote preflight/previews. No server or ESP firmware update is required. Existing data and updater signing key are preserved; the installer is not Authenticode-signed.

## Проверки / Validation

- 181 Rust tests passed, one existing hardware-only test skipped; 699 TypeScript tests passed. Formatting, lint, types, doctests and dependency policies passed locally.
- Production dependency audit found no known vulnerabilities. Manual review covered changed request authorization, response bounds, no-input preflight, same-frame encoding and stale result handling. Gitleaks, Semgrep, OSV Scanner and cargo-audit were unavailable; their absence is not a pass.
- Editor UI was checked at 1280×720 and 600×900, in Russian/English, with preflight dialogs in all six Toffee/Cocoa/Forest light/dark combinations. Same-frame image/OCR displays, enlarged preview, jump-to-block and parameter differences were verified using synthetic hardware/account responses. These checks do not verify physical ESP execution, a live remote PC or production account synchronization.
- The installer build, update signature, GitHub CI and downloaded artifact hashes are recorded separately in release-manifest.json. Installing over the user's running application and interactive native acceptance were not performed during this task; a clean Windows VM was unavailable.

Rollback: reinstall 0.28.0 if necessary. There is no scenario format or server schema migration. Keep exported scenarios and local/account history before rollback.
