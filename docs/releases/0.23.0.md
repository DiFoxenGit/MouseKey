# MouseKey 0.23.0

## Русский

Конструктор переработан по выбранному компактному варианту: карточки сценариев занимают меньше высоты, целевой компьютер и повторы видны рядом с запуском, основные параметры блока расположены первыми. Имя, сохранение и связи раскрываются отдельно. На небольшом окне палитра и параметры открываются боковыми панелями; высота полотна подстраивается под свободное место, ручной размер сохраняется.

В палитре появились поиск, избранные и недавние действия. Подписи блоков показывают две строки, связи выбранного блока подсвечиваются. Нижняя библиотека получила меню операций с аккаунтом и отметку различий между локальной и облачной копиями.

Поиск изображения разделён на «Где искать», «Что искать» и «После совпадения». Миниатюры крупнее, допуск цвета объясняет разницу RGB-каналов, результат проверки показывает процент и схему положения найденного эталона. Полноэкранный поиск сохраняет точность и больше не ограничивается старым фиксированным числом сравнений.

Полотно перемещается зажатой ЛКМ по пустому месту; ЛКМ + колесо меняет масштаб по 1%, обычное колесо прокручивает страницу. Ошибки действий появляются справа внизу и исчезают через 6 секунд, таймер приостанавливается при чтении. Применено общее оформление полос прокрутки.

Установщик обновляет приложение с сохранением данных. Для исправленного поиска обновите оба ПК. Прошивка ESP прежняя. Сохранение в аккаунт остаётся явным действием. Формат сценариев не менялся.

## English

The approved compact designer is implemented: shorter scenario cards, visible target/repeat settings, action parameters first, collapsible naming/saving/connections, narrow-window side panels and canvas height fitted to available space with a persistent manual override.

The action palette adds search, favorites and recent actions. Blocks have two-line summaries and selected connections are highlighted. The bottom library has an account operations menu and explicit local/account difference status.

Image search is grouped into search area, templates and match behavior, with larger thumbnails, an explanation of RGB color tolerance, and a match-position diagram plus percentage. Full-screen matching retains exactness without the old fixed comparison limit.

Drag empty canvas space to pan; hold the left button and use the wheel to zoom by 1%. Ordinary scrolling moves the page. Action feedback appears at the bottom right for 6 seconds, pausing while read; shared scrollbar styling is applied.

The installer preserves existing data. Update both PCs for image-search fixes; ESP firmware is unchanged. Account saving remains explicit and scenario storage format is unchanged.
