# MouseKey 0.24.1

## Русский

- Масштаб полотна теперь меняется по **5%**: зажмите ЛКМ на пустом месте и вращайте колесо. Кнопки приближения и отдаления используют тот же шаг.
- Убран скачок при продолжении перетаскивания после колеса в Windows. Текст схемы больше не выделяется при перемещении полотна.
- Точечный фон заполняет всё полотно и не обрывается при смещении или уменьшении масштаба.
- Убрана надпись «Готово к настройке» под сохранёнными блоками. Состояние выполнения и результат сценария остаются видимыми.

Установщик сохраняет настройки и сценарии. Формат сценариев не менялся, прошивку ESP обновлять не нужно. Обновление подписано прежним ключом проекта.

## English

- Canvas zoom now changes in **5%** steps: hold the left mouse button on empty canvas space and turn the wheel. Zoom buttons use the same step.
- Fixed the Windows drag jump after wheel zoom. Panning no longer selects diagram text.
- The dotted background fills the entire viewport without blank edges when panning or zooming out.
- Removed the “Ready to edit” footer below saved blocks while retaining execution status and results.

The installer preserves settings and scenarios. Scenario formats and ESP firmware are unchanged. Updates use the existing project signing key.
