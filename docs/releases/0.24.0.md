# MouseKey 0.24.0

## Русский

В конструкторе появилась миникарта: нажмите или перетащите указатель по ней, чтобы быстро перемещаться по большой схеме. Карту можно скрыть кнопкой на панели; при фокусе на ней работают стрелки и Home.

Выполняемый блок подсвечивается и получает отметку «Выполняется». Кнопка «К текущему блоку» центрирует его на полотне. После ошибки или ручной остановки остаётся видимым место остановки.

История рядом с запуском сохраняет на этом ПК последние 50 ошибок и остановок. Запись содержит время, сценарий, блок и причину; «Перейти к блоку» открывает схему, выделяет нужное действие и перемещает к нему вид. История остаётся после перезапуска, её можно очистить отдельно от сценариев. Если блок удалён, запись сохраняется с понятным объяснением.

Отслеживание учитывает условия, циклы, обратные связи, вложенные сценарии и запуск с выбранного шага. Для удалённой подсветки и истории обновите MouseKey на обоих ПК. Сохранённые сценарии совместимы, прошивку ESP менять не нужно. Быстрые действия между обновлениями статуса могут не успеть подсветиться; место ошибки сохраняется.

Установщик обновляет приложение с сохранением настроек и сценариев. Обновление подписано прежним ключом проекта.

## English

The designer now has a minimap: click or drag to navigate a large graph, toggle it from the canvas toolbar, or use arrow keys and Home when it has keyboard focus.

The executing block is highlighted with a Running marker. Current block centers it on the canvas; a terminal error or manual stop retains its location.

Errors and stops next to the run controls stores the last 50 records locally across restarts. Each record shows the time, scenario, block and reason. Go to block opens the scenario, selects the affected action and centers the canvas. History can be cleared independently; deleted blocks remain documented with a clear explanation.

Tracking covers branches, loops, back edges, nested scenarios and starting from a selected step. Update both PCs for remote tracking. Saved scenarios remain compatible and ESP firmware is unchanged. Short actions may finish between status samples; the failure location is retained.

The installer preserves existing settings and scenarios. The update uses the existing project signing key.
