# MouseKey 0.25.0

## Русский

### ✨ Новое

- Перетащите карточку сценария на полотно другого — получится **связанный блок**. Редактирование оригинала применяется во всех местах использования при следующем запуске; можно открыть оригинал и вернуться к родителю.
- **Найти места использования** показывает конкретные блоки и позволяет перейти к ним. Используемые оригиналы защищены от удаления.
- Выбирайте группу через **Ctrl/Shift + клик**, **Shift + рамку** или кнопку «Выделить». Доступны совместное перемещение, дублирование внутренних связей, сворачивание и удаление с отменой.
- Кнопка **«Сохранить»** записывает на ПК и в аккаунт вместе со связанными сценариями. Если другой ПК изменил версию, появится предупреждение: локальная работа сохраняется, автоматической перезаписи нет.

### 🛠 Исправления и оформление

- Библиотека блоков больше не съезжает после удаления. Добавлены фильтры категорий, плавная перестановка карточек и отмена нескольких удалений.
- Единый стиль карточек и панелей; верхний список сценариев и нижнюю библиотеку можно сворачивать.
- Выполняемый блок выделяется **зелёным** на схеме и миникарте, чтобы отличаться от обычного выделения.
- Устранена лишняя перезапись сценариев при изменении независимой библиотеки заготовок.

### ⚠️ При обновлении

Настройки и сценарии сохраняются. Для работы связанных сценариев обновите редактор на всех ПК: старые версии не понимают ссылки на оригиналы. Существующие независимые заготовки продолжают работать. JSON и EXE экспортируют автономный снимок. Прошивку ESP обновлять не нужно. Подпись обновлений использует прежний ключ проекта.

Отслеживание выполнения остаётся с интервалом 250 мс: очень короткие действия могут не успеть отобразиться. Конфликты аккаунта проверены автоматическими тестами; одновременный тест на двух физических ПК не проводился.

### Проверки и откат

Локально пройдены 626 тестов интерфейса, 170 тестов Rust, 15 тестов механизма установки и 2 теста упаковки; проверки типов, форматирования, линтеров и зависимостей. Один аппаратный тест остаётся пропущенным. Конструктор проверен в 18 сочетаниях темы, палитры и ширины окна; связанные сценарии, переходы к использованию и групповое удаление с отменой — также в нативном приложении на отдельном профиле.

Для отката сначала экспортируйте нужные сценарии в автономный JSON и сохраните резервную копию профиля, затем используйте установщик [0.24.1](https://github.com/DiFoxenGit/MouseKey/releases/tag/v0.24.1). Не редактируйте связанные оригиналы старой версией: она не поддерживает новый формат ссылок. При отзыве этого выпуска канал обновлений возвращается к предыдущему релизу; установленные копии автоматически не понижаются.

## English

### ✨ New

- Drag a scenario card onto another canvas to create a **live reference**. Source edits apply at every usage on the next run. Open the source and return to the caller.
- **Find usages** lists exact caller blocks and navigates to them. Referenced originals cannot be deleted.
- Select groups with **Ctrl/Shift-click**, **Shift-drag** or selection mode; move, duplicate internal wires, collapse or delete them with undo.
- **Save** persists locally and uploads the selected scenario and its dependencies. Concurrent account edits produce a warning while preserving local work; there is no silent overwrite.

### 🛠 Fixes and appearance

- Fixed the saved-block grid collapsing after deletion. Added category filters, animated rearrangement and multi-step deletion undo.
- Consistent cards and panels, with collapsible scenario and block shelves.
- The executing block is highlighted **green** on the canvas and minimap, distinct from selection.
- Updating the independent preset library no longer rewrites scenario documents unnecessarily.

### ⚠️ Updating

Settings and scenarios are preserved. Update editors on every PC that uses live references; older versions do not understand source links. Existing snapshot presets remain supported. JSON/EXE export resolves a standalone snapshot. No ESP firmware update is needed. Updates use the existing project signing key.

Execution polling remains at 250 ms, so very short actions may not appear. Account conflicts were covered by automated tests, not a simultaneous two-physical-PC session.

### Validation and rollback

Local validation passed: 626 frontend tests, 170 Rust tests, 15 installer engine tests and 2 packaging tests, plus types, formatting, linters and dependency checks. One hardware test remains skipped. The builder was checked in 18 theme, palette and width combinations; live references, usage navigation and group delete/undo were also verified in the native app with an isolated profile.

Before rollback, export required scenarios as standalone JSON and back up the profile, then use the [0.24.1 installer](https://github.com/DiFoxenGit/MouseKey/releases/tag/v0.24.1). Do not edit live references with the older editor, which does not support them. If this release is withdrawn, restore the previous update channel release; installed copies are not automatically downgraded.
