# MouseKey 0.26.0

## Русский

### ✨ Копирование блоков

- Выделите блок или группу и нажмите **Ctrl+C**, затем **Ctrl+V** в том же или другом сценарии. Сохраняются настройки, эталоны изображений и связи внутри группы.
- Вставка создаёт независимые блоки с новыми идентификаторами, выделяет их и отменяется одним действием. Живые ссылки на сценарии сохраняют связь с оригиналами.
- Обычное копирование текста в полях работает как раньше. Во время выполнения сценария вставка блоков заблокирована.

### 🛠 Надёжнее сохранение

- После сбоя сети можно снова нажать **«Сохранить»**: больше не требуется отдельно обновлять аккаунт, чтобы отправка возобновилась.
- Исправлены ложные конфликты последовательных сохранений и обработка потерянного ответа сервера.
- Изменение другого сценария на втором ПК больше не мешает сохранить текущий. Настоящие изменения одного сценария с двух сторон защищены от автоматической перезаписи.
- Сохранение вложенного сценария больше не создаёт ложную отметку об отличающейся копии родителя из-за служебного снимка ссылки.
- Карточки различают **изменения на ПК**, **изменения в аккаунте** и **изменения с двух сторон**. Ошибка сети или истёкший вход не выдаются за успешную отправку.
- Проверены редактирование во время сохранения, смена аккаунта, ошибка локального хранилища и удаление используемого сценария.

### ⚠️ При обновлении

Настройки и сценарии сохраняются. Обновите редакторы на используемых ПК для одинакового поведения сохранений. Прошивку ESP менять не нужно; серверный протокол прежний. Подпись автообновления использует прежний ключ проекта. Установщик Windows не имеет Authenticode-подписи.

Защита параллельных правок использует основу сравнения текущего сеанса конструктора; долговременная история версий и сверка изменений между перезапусками пока не реализованы. Сбои и конфликты проверены изолированными тестами; одновременный тест двух физических ПК через интернет не проводился.

## English

### ✨ Block clipboard

- Select one block or a group, then press **Ctrl/Cmd+C** and **Ctrl/Cmd+V** in the same or another scenario. Settings, reference images and internal wires are preserved.
- Paste creates fresh block IDs, selects the inserted group and supports one-step undo. Live scenario references stay linked to their originals.
- Text fields retain native clipboard behavior. Block insertion is disabled while a scenario is running.

### 🛠 Reliable saving

- Retry **Save** after a network failure without a separate account refresh.
- Fixed stale revisions on consecutive saves and recovery after lost server acknowledgements.
- Concurrent edits to unrelated scenarios no longer block the current save. Overlapping changes to the same scenario remain protected against automatic overwrite.
- Cached child previews no longer create false differences in linked parents after saving a source scenario.
- Cards distinguish **local**, **remote** and **two-sided** changes. Network/session errors cannot be mistaken for successful uploads.
- Covered editing during upload, account switches, local storage failures and deletion of referenced scenarios.

### ⚠️ Updating

Settings and scenarios are preserved. Update the editors on your PCs for consistent saving behavior. No ESP firmware or server protocol change is required. Updates use the existing project signing key; the Windows installer is not Authenticode-signed.

Concurrent-edit protection uses the current editor session's baseline. Persistent version history and cross-restart reconciliation remain future work. Failure and conflict checks used isolated fixtures, not simultaneous physical internet peers.
